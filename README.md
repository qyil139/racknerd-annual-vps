## 条款里几个容易忽略的限制

**默认不退款。** 官方知识库写得很直接：按服务条款，不提供退款，也没有退款保证。账户余额（预充值）同样不可退。想试可以先买最小配置，别一次充几百美元进去。

**取消要提前 5 天。** 得在续费日前至少 5 天通过客户中心提交，取消后数据立即删除，先备份再点。

**逾期 3 天可能收 10% 滞纳金。** 账单到期 7 天仍未付款，大部分服务会被系统自动终止，数据无法恢复。独服更严，最早到期 3 天就可能被回收。

**1G 套餐别选 Debian 11/12。** 下单页有提示，Debian 11/12 建议至少 2G 内存。1G 装 Ubuntu 24.04 或 Debian 13 更稳。

**VPS 没有通用优惠码。** 截至 2026 年 11 月官网没有 VPS 优惠码，网上流传的多是过期旧码，不用逐个试。独服有 `15OFFDEDI`，官网横幅在列，所有独服终身减 15%，E3-1230 v2 折后约 $118.15/月（计算值），只对独服有效。

**不支持嵌套虚拟化。** 服务条款写明，未经书面批准不能在 KVM VPS 里再跑虚拟机、VPS 平台或需要硬件虚拟化的模拟器。Docker、Docker Compose、LXC/LXD、Kubernetes、K3s 这类容器负载没问题。想开小鸡得买独服。

**数据安全自己负责。** 条款写明 RackNerd 不对数据完整性负责，默认不含托管备份。异地备份自己做。

**禁止挖矿、发垃圾邮件、暴力破解、对外 DDoS。** 违规停机，不退款。

下单前按这五步测一遍：

1. 本机 ping 测试 IP 至少 50 次，看平均延迟和丢包率
2. 白天测一次，晚高峰 20:00–23:00 再测一次，两个结果差距大说明线路拥塞
3. 用 mtr 或 traceroute 看路由走向，找丢包出现在哪一跳
4. 用多节点 ping 工具看电信、联通、移动三网结果，别只测自己家的宽带
5. 访客主要在美国或做外贸站，直接选离客户最近的机房，不用纠结回国延迟

洛杉矶 DC03 对西海岸和亚太方向更友好，纽约偏东海岸和欧洲。移动、联通用户的实际表现差异可能很大，测完再下单。买 1G 那款试一个月成本 $21.99，比事后换机房省事。

## 常见问题

**续费会涨价吗？**
不会。Specials 页 FAQ 写明这些特价是 lifetime recurring，不取消就一直按购买时的价格续费。

**不满意能退款吗？**
默认不退款，官方知识库明确说明没有退款保证。账户余额也不可退。只能个案联系客服协商。

**支持支付宝吗？**
支持。结账页显示 Stripe 支付宝、银联卡、PayPal、信用卡、USDT/USDC 等，没有微信支付。

**哪个机房国内最快？**
官网没给回国线路信息，也没公布延迟数据。用上面四个特价机房的测试 IP 自己测，晚高峰 20:00–23:00 的结果才有参考价值。

**网上说的 $9.89/年是怎么回事？**
那是历史黑五限量款的价格，当前官网 Specials 页最低是 1G 的 $21.99/年。超低价套餐通常限量、限时、售完即止，以官网当前挂牌价为准。

**IPv6 怎么申请？**
下单后开工单，洛杉矶和法国机房可免费申请最多 100 个，其他机房以客服答复为准。

**能跑 Docker 吗？**
能。KVM 虚拟化加完整 root，ctrl 面板里有一键装 Docker + Portainer 的入口，也可以 SSH 自己装。嵌套虚拟化不行。
